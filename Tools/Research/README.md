# Εξαγωγή δεδομένων αξιολόγησης

Η τρέχουσα ροή (`campaign-final-meega-el-3`) έχει δημογραφικά MEEGA+ και στη συνέχεια αρχικές γνώσεις και τάσεις μετά τον πρόλογο, 20 υποθέσεις σε 10 πρυτανείες και, στο τέλος, τελικές γνώσεις, τάσεις και εμπειρία MEEGA+. Δεν υπάρχει ενδιάμεση αξιολόγηση ή ερώτηση ανά υπόθεση.

Τα ερωτήματα τάσεων είναι προσωρινά, μη επικυρωμένα placeholders. Τα δεδομένα τους εξάγονται χωριστά από τις πραγματικές επιλογές των υποθέσεων και τις διαστάσεις εμπειρίας. Δεν προκύπτει διάγνωση πραγματικής πολιτικής ιδεολογίας.

## Εκδόσεις

Τα όργανα έρευνας βρίσκονται στο `Assets/Content/ContentLibrary.asset` (ενότητα «Όργανα έρευνας»). Το `Tools → Content → Validate Content` και το prebuild check παγώνουν αυτόματα το ακριβές runtime ερωτηματολόγιο στο `Instruments/<version>-<hash>.json`. Η τηλεμετρία και η εξαγωγή χρησιμοποιούν το ίδιο hash. Διατήρησε αυτά τα στιγμιότυπα μαζί με τις εξαγωγές και το build. Τα `EvaluationContent.json` και `EvaluationContent.legacy.json` αφορούν παλαιότερες εκδόσεις και παραμένουν μόνο για συμβατή ανάγνωση ιστορικών εγγραφών.

## Ανάκτηση

Χρειάζεται Google Cloud CLI και λογαριασμός με δικαίωμα ανάγνωσης (π.χ. `roles/datastore.viewer`). Η σύνδεση γίνεται από τον ερευνητή με `gcloud auth login`. Δεν απαιτείται service-account key ούτε δημοσίευση token. Εκτέλεσε `python pull_firestore_events.py --help` για τις παραμέτρους της μόνο για ανάγνωση ανάκτησης. Αποθήκευε ιδιωτικά τις πρωτογενείς εξαγωγές, εκτός Git και Unity Assets.

## Τοπική εξαγωγή

Από αυτόν τον φάκελο:

```powershell
python export_evaluation.py --input 'C:\ResearchPrivate\events.json' --output 'C:\ResearchPrivate\analysis'
```

Ο exporter διαβάζει αυτόματα τα παγωμένα εργαλεία από `Instruments`. Μπορείς να προσθέσεις παλαιότερα παγωμένα αρχεία με `--content`. Τα διαφορετικά hashes, runs και εκδόσεις διατηρούνται χωριστά.

Παράγονται οι προηγούμενοι πίνακες γνώσεων, εμπειρίας και αποφάσεων, και επιπλέον:

- `Demographics.csv`: ηλικιακή ομάδα, φύλο, συχνότητα ψηφιακών και μη ψηφιακών παιχνιδιών, προαιρετικό εκπαιδευτικό πλαίσιο· συνδέονται με τις άλλες απαντήσεις ανά συμμετέχοντα και run.
- `Tendencies-Responses.csv`: κάθε αρχική/τελική απάντηση με σταθερό ID, ακριβές κείμενο, κλίμακα, έκδοση, σημείο χορήγησης και χαρακτηρισμό placeholder.
- `Tendencies-Paired.csv`: σύζευξη ανά συμμετέχοντα, run, ερώτημα και εκδόσεις. Μεταβολή υπολογίζεται μόνο με αμφότερες τις απαντήσεις. Το `reverse` επηρεάζει μόνο την κωδικοποιημένη στήλη· η αρχική απάντηση διατηρείται.
- `agora_votes.csv`: μία γραμμή ανά ψηφοφορία· κάθε όρος της ανάλυσης σε δική του στήλη (`line_Base`, `line_Pressure`, …, `line_Mood`), άθροισμα, αποτέλεσμα, για ποια πλευρά μίλησε και τι ψήφισε ο παίκτης.
- `agora_trials.csv`: μία γραμμή ανά δίκη· αν κατηγόρησε, χώρος, στοιχεία, οι όροι του D, ετυμηγορία, συκοφάντης, ψήφος δικαστή.
- `agora_prytanies.csv`: οι 9 δείκτες (4 του παίκτη, 5 της πόλης) στο τέλος κάθε πρυτανείας.
- `agora_endings.csv`: τέλος πόλης, τέλος παίκτη και `knowledgeFormOrder` (πάντα «AB»: μορφή Α πριν, Β μετά, χωρίς αντιστάθμιση).
- Στο `knowledge.csv` η στήλη `shown_order` δίνει τη σειρά των επιλογών που είδε ο παίκτης (ids, π.χ. «c,a,d,b»).
- `Quality.json`: σφάλματα, προειδοποιήσεις και έλεγχοι.
- `Summary.json`: περιγραφικές συνοψίσεις και πλήθος ζευγών τάσεων.

Το -1 σημαίνει μη απαντημένο. Το 0 επιτρέπεται μόνο ως μη εφαρμόσιμο σε στοιχεία MEEGA+ που το προβλέπουν. Δεν γίνεται συμπλήρωση ελλειπουσών απαντήσεων. Οι νέες αξιολογήσεις έχουν `full-campaign` έκθεση, ενώ παλαιότερες εκδόσεις διατηρούν την προηγούμενη ταξινόμησή τους.

## Έλεγχοι και συνθετικά δεδομένα

```powershell
python -m unittest test_research_export -q
node test_research_js.mjs
```

Το `test_research_js.mjs` τρέχει το `research.js` του build σε ψεύτικο browser (χωρίς δίκτυο) και ελέγχει ότι κάθε έγγραφο που θα έστελνε περνά τους κανόνες του `firestore.rules`: επιτρεπτά κλειδιά, υποχρεωτικά πεδία, όρια τιμών, μέγεθος `sourceRef`, και ότι χωρίς συγκατάθεση δεν φεύγει τίποτα.

Τα συνθετικά δεδομένα αποκλείονται από προεπιλογή. Για χωριστό τεχνικό fixture χρησιμοποίησε `--include-synthetic`. Δεν αποτελούν στοιχεία πραγματικών συμμετεχόντων και δεν αποστέλλονται στην παραγωγική βάση από τις τοπικές δοκιμές.


Το build/Validate JSON παγώνει επίσης το ακριβές runtime σύνολο υποθέσεων στο `Tools/Research/CaseBanks`. Το `Tools/Research/StudyManifest.json` συνδέει τα δύο ακριβή αρχεία της τελευταίας επικύρωσης. Φύλαξε αντίγραφό του μαζί με το build που αξιολογείται. Ο puller το χρησιμοποιεί εξ ορισμού· για διαφορετικό build δώσε `--study-manifest` με το δικό του παγωμένο manifest. Παράδειγμα μόνο για ανάγνωση: `python pull_firestore_events.py --output C:/ResearchPrivate/events.json`. Με `--dry-run` ελέγχεται το πλάνο χωρίς σύνδεση ή δίκτυο.

Τα δημογραφικά βασίζονται στην προσαρμογή του προφίλ MEEGA+ 2018 που περιγράφεται στο `Assessments/Demographics.json`. Οι κατηγορίες μη δήλωσης και άλλο φύλο είναι προσθήκες της παρούσας εφαρμογής. Δεν συλλέγεται ονοματεπώνυμο ή ημερομηνία γέννησης στη φόρμα. Οι ερωτήσεις γνώσεων δεν εμφανίζουν ανατροφοδότηση ορθότητας κατά τη χορήγηση· η ορθότητα υπολογίζεται στην ανάλυση.
